# Hosting the static site (free)

Files: index.html, research.html, conferences.html, teaching.html, contact.html, style.css, images/profile.jpg

## Option A: Cloudflare Pages (simplest, also sells domains at cost)
1. Create a free Cloudflare account, go to Workers & Pages > Create > Pages > Upload assets.
2. Drag in this folder, deploy. You get a free *.pages.dev address.
3. Custom domain: Pages project > Custom domains > Set up a domain, follow the DNS steps.

## Option B: GitHub Pages
1. Create a GitHub repo, upload these files, Settings > Pages > Deploy from branch (main, root).
2. Custom domain: Settings > Pages > Custom domain, then add the DNS records GitHub shows at your registrar.

## Domain
Buy at a registrar such as Cloudflare Registrar, Porkbun or Namecheap. Payment and account creation are yours.
